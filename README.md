# 🌿 MindBloom — AI-Powered Mental Wellness Platform

MindBloom is an AI-powered mental wellness platform designed to help students, working professionals, and anyone who wants to better understand and manage their emotional well-being.

It combines mental wellness assessments, mood tracking, personalized wellness activities, progress monitoring, and an AI wellness companion into one modern and accessible platform.

> **MindBloom supports mental wellness and self-reflection. It is not a replacement for professional medical advice, diagnosis, or treatment.**

---

## 💡 The Problem

Mental wellness support can often feel difficult to access, overwhelming, or disconnected.

Many people experience stress, anxiety, poor sleep, low mood, and emotional pressure but may not have an easy way to regularly check in with themselves, understand patterns, or discover simple wellness activities.

## 🌱 Our Solution

MindBloom provides a single digital wellness space where users can:

- Complete structured mental wellness assessments
- Track their mood and emotional progress
- Receive personalized wellness recommendations
- Practice breathing, grounding, meditation, and other activities
- Interact with an AI-powered wellness companion
- Review previous assessments and conversations
- Build personalized wellness plans
- Track achievements and progress over time

The goal is to make everyday mental wellness support more approachable, interactive, and accessible.

---

## ✨ Key Features

### 🧠 Mental Wellness Assessment
Structured self-assessments across key wellness areas including:

- Anxiety
- Stress
- Mood
- Sleep Quality
- Self-Esteem

Users receive easy-to-understand results that help them reflect on their current wellness state.

### 🤖 Bloom AI Companion
An AI-powered conversational wellness companion designed to provide supportive and non-judgmental conversations.

It supports:

- English
- Urdu
- Roman Urdu

Bloom focuses on emotional support, wellness guidance, and healthy self-reflection rather than medical diagnosis.

### 📊 Personal Wellness Dashboard
A personalized dashboard provides users with an overview of their wellness journey, including assessments, mood information, activities, and progress.

### 😊 Mood Tracking
Users can record their mood and build a clearer picture of emotional patterns over time.

### 🧘 Wellness Activities
MindBloom includes practical wellness activities such as:

- Box breathing
- Meditation
- Grounding exercises
- Stress management
- Self-compassion
- Positivity exercises
- Sleep routines
- Healthy morning routines

### 📚 Wellness Hub
A dedicated collection of wellness resources and educational content designed to help users learn practical techniques for everyday well-being.

### 📈 Assessment & Chat History
Registered users can revisit previous assessment results and AI companion conversations.

### 🏆 Achievements
Progress and engagement are encouraged through an achievement-based experience.

### 🌙 Light & Dark Mode
The interface supports both light and dark themes for a comfortable and modern user experience.

### 🛡️ Admin Dashboard
MindBloom also includes an administrative interface for managing and monitoring platform content and user-related functionality.

## 🗄️ Database

The database export/schema is included in:

```text
/database/
```

To set up the database locally:

1. Start Apache and MySQL using XAMPP.
2. Open phpMyAdmin.
3. Create a new database for MindBloom.
4. Import the `.sql` file provided inside the `database` directory.
5. Configure your local backend database connection as required.

> Do not commit production credentials, API keys, passwords, or other secrets to the repository.

## 🚀 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/ManhaFatime/MindBloom-AI-Powered-Mental-Wellness-Platform.git
```

### 2. Enter the project directory

```bash
cd MindBloom-AI-Powered-Mental-Wellness-Platform
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create the required local environment configuration for any API keys or secrets used by the project.

Never expose private API keys directly in frontend source code or commit them to GitHub.

### 5. Configure the backend

Set up the PHP backend using XAMPP/Apache and configure the MySQL database connection for your local environment.

### 6. Start the frontend

```bash
npm run dev
```

Open the local development URL shown in your terminal.
